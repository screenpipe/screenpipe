| Idle readiness checks keep completing | Show the unfinished update once durable progress is stale | Reset the preparing grace period on every no-op | Adapter tests and real component captures, before/after. |

Private workflow requests now cap the SDK request timeout at 120 seconds and
leave retries to Pi. Chat retains its existing request policy. The total Pipe
run timeout and schedule are unchanged. Checkpoints replace one note per role,
limited to 8000 Unicode characters, through the existing catalog writer. They
never update workflow evidence or checkedThrough. Raw screenshots and captures
are not copied into checkpoints.

The new instructions explicitly expose checkpoint/resume and narrowed-query
recovery. Automatic migration recognizes exact shipped bodies and preserves
custom instructions, enabled state, model, timeout, trigger and custom schedules.
The existing agent-trial fixture accepts the same checkpoint action so a future
matched baseline/candidate run can exercise it.

The initial checks did not include a live-model trial or installed-app run. A deterministic
pass establishes the runtime contracts, not better workflow quality in real use.
A follow-up matched trial should hold model, source history and run budget fixed
and compare whether the same authorized investigation completes with valid
sources, including the no-change and stopped cases above.

The follow-up [GLM compaction evaluation](glm-compaction-live.md) exercises real
summaries and continuations through the private model transport. It found and
repairs evidence truncation and acceptance of incomplete summaries. That is a
component replay, not an end-to-end trial of the four shipped workflow prompts.
