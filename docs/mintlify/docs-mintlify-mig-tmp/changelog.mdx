## week of may 3, 2026

### new features

- **meeting notes redesign** — promoted to the main sidebar with a two-pane notepad, a "coming up" calendar section, an active-meeting state, a timeline scrubber for navigating recordings, plus replay-the-moment and summarize bundles. queries both native and Google Calendar. [learn more](/meeting-transcription).
- **Zoom OAuth** — connect Zoom from **settings → connections** to bring meeting data into screenpipe. [see connections](/connections).
- **Jira via OAuth 2.0 (3LO)** — Jira now uses standard OAuth, no maintainer setup needed.
- **Supabase OAuth** — connect Supabase as a managed integration. [see connections](/connections).
- **Bee wearable + Hermes Agent** — new connection cards for the Bee wearable and the Hermes coding agent (paste screenpipe MCP into your Hermes config).
- **clipboard capture privacy toggle** — opt out of clipboard capture from the UI or via a CLI flag. [privacy filter](/privacy-filter).
- **one-click retention controls** — delete the last 15, 30, or 60 minutes of recordings from the UI. a new media-only retention mode reclaims disk while keeping search alive; configurable via `--retention-mode`. [CLI reference](/cli-reference).
- **tray "pause for X minutes"** — pause recording from the tray menu with auto-resume; the tray tooltip shows live status and notifies on pause/resume.
- **Connections in the main sidebar** — promoted from settings for faster access.
- **queue follow-up prompts in chat** — keep typing while pi is streaming; messages run in order.
- **embedded agent browser** — an owned browser opens as a right-side sidebar for chat conversations, with a `/navigate` and `/snapshot` API. width and collapsed state persist per conversation.
- **MCP server LAN access** — `--listen-on-lan` and `--api-key` flags let other devices on your network reach the MCP HTTP server. [MCP server](/mcp-server).
- **one-off scheduled pipes** — schedule a pipe to run once at a specific time with `schedule: at <iso>`. [pipes](/pipes).
- **`screenpipe install <manifest-url>`** — install pipe bundles from a manifest URL. [CLI reference](/cli-reference).
- **streaming onboarding summary** — onboarding now streams a "here's what i picked up" recap with thumbnails as recordings come in.
- **timeline search polish** — ⌘G to step through matches, a dot strip showing match density, and a gentle pulse on the active hit.

### updates

- **single recording quality knob** — replaces multiple settings; fixes unreadable text on ultrawide displays.
- **OpenAI model catalog is now live** — preset picker reflects the actual available models instead of a hardcoded list.
- **AI presets default to "auto"** — stale qwen presets are migrated automatically; pro vs non-pro defaults are seeded the first time we know your account tier.
- **chat polish** — queued messages are de-emphasized, the first thinking block collapses by default, thinking and tool blocks auto-expand when there's no prose, the sidebar dot pulses while the current chat streams, and chat renames sync live across windows.
- **per-line accessibility text capture** — multi-line text fields now report per-line bounding boxes on macOS, including in Chromium browsers.
- **macOS system audio** uses CoreAudio Process Tap by default on 14.4+; this continues from last week's rollout.
- **help menu** — added Documentation and Video tutorials cards.

### bug fixes

- **chat reliability** — user messages persist on send, "writing…" indicators self-heal on session return, deleted chats stay deleted (pi process is aborted), assistant messages persist during streaming (not only on stream-end), and concurrent saves no longer collide. pipe-run sessions on Windows are no longer silently lost due to invalid filenames, and history loss on rename has been fixed.
- **chat sidebar** — "+ new chat" opens a real new thread instead of jumping to an old one; backgrounded panel sessions don't get marked unread; scheduled pipes keep a stable FIFO order.
- **meeting notes** — broken frame images and a scrubber that ended too early are fixed; the sidebar can be expanded again during a focused meeting; recording stop button works and a push-driven status stream replaces polling.
- **timeline** — empty-state arrow buttons now navigate the right direction; search nav chevrons swapped so ▶ goes forward in time; per-word search highlights are tighter; Escape works on the overlay timeline when opened from search (Windows).
- **retention** — "delete last N minutes" now actually removes mp4/wav files and clears cached frames.
- **audio** — zero-fill watchdog only trips after the stream was healthy, preventing false positives on input device hijacks.
- **vision-stall false alarms** — the health check no longer trips when the database is busy de-duplicating frames.
- **remote sync** — uses `VACUUM INTO` snapshots to prevent corrupt `db.sqlite` uploads.
- **OCR** — Apple per-word records are preserved on the level-0 fast path.
- **MCP `list-meetings`** — accepts relative date strings ("yesterday", "last week"); `merge-speakers` JSON field names corrected.
- **AI gateway** — `reasoning_content` is promoted to `content` when the response body is otherwise empty; model aliases now apply to the request body, not just provider routing.
- **owned browser** — survives tray-only mode, picks any available window as a parent, fixes screen-coordinate math, and spoofs Safari UA so x.com loads.
- **browser extension** — MV3 keepalive every 30s and retry on owned-browser install fixes flapping; ineligible tabs (`chrome-extension://`) are skipped.
- **connections** — Google Calendar status dot shows correctly when not connected; pipes can be disabled even if their connections are missing; loading and retry replace blank panel on errors.
- **windows** — title text hidden on login and Google Calendar OAuth webviews; remaining `cmd`/`where` console flashes suppressed; theme contrast issues resolved between light and dark modes.
- **notifications** — file links rewrite to the in-app viewer; settings link navigates correctly; updater errors no longer propagate to callers.
- **shortcuts** — recording cancels on Esc / click-outside with clearer UX labels.

## week of april 26, 2026

### new features

- **new integrations** — connect [Microsoft 365 and Teams](/connections), Google Docs, Google Sheets, QuickBooks Online, Bitrix24, Loops, Resend, Supabase, and the Pocket AI voice recorder. configure in **settings → connections**.
- **PII privacy filter** — opt-in filter (powered by a Tinfoil enclave) that redacts personal info from `/search` results and chat messages before they leave your machine. toggle from the chat composer. [learn more](/privacy-filter).
- **parallel chats with background streaming** — start multiple chats and switch between them; responses keep streaming in the background. a new chat sidebar shows pinned chats, recents, and pipes scheduled to run.
- **focus-aware capture** — when enabled, screenpipe only records the focused monitor instead of all of them, halving capture cost on multi-display setups. toggle from settings.
- **per-machine pipe favorites** — star pipes you use most. starred pipes sort to the top of the pipe list and get their own filter chip.
- **LAN-access toggle for the API** — bind the local API to `0.0.0.0` so other devices on your network can reach it. API auth is force-enabled when LAN access is on. see the [API docs](/for-developers).
- **`screenpipe sync remote`** — back up your screenpipe data over SSH/SFTP to a server you control. see the [CLI reference](/cli-reference).
- **`screenpipe db {check, recover, cleanup, unlock}`** — new CLI commands to repair database corruption and reclaim disk space. see the [CLI reference](/cli-reference).
- **`screenpipe logout`** — sign out of your screenpipe cloud account from the CLI.
- **connected apps as @mentions in chat** — type `@` in the chat filter popover to scope a question to a specific connected integration.
- **AI quota warnings** — heads-up notice when you're close to your daily limit on weighted models, so you don't get cut off mid-task.
- **browser extension v0.2** — new popup with connection status, an options page, and token-based auth.

### updates

- **CoreAudio Process Tap is now the default for system audio** on macOS 14.4 and later — better quality and no virtual driver required.
- **API keys are now readable and regeneratable** in the UI. user-set custom keys have been removed in favor of a single managed key.
- **Cursor-style inline edit** — click any of your past chat messages to edit and re-run it.
- **redesigned sidebar** — collapse button next to the macOS traffic lights, search opens a focused overlay window with a real keyboard shortcut, and starred pipes outrank running pipes in sort order.
- **timeline calendar** — empty days are now disabled in the day picker and skipped when navigating with arrow keys.
- **chat models hot-swap** — switching a preset's model no longer restarts the chat subprocess.

### bug fixes

- **mic stays connected on sleep/wake** — fixed false-positive disconnects.
- **Microsoft 365 / Teams OAuth** now uses the correct Azure client ID; personal Microsoft accounts are rejected up-front (Teams scope isn't supported there).
- **database reliability** — multibyte string truncation no longer panics, and connection starvation under heavy writes has been resolved.
- **diarization timeouts** — added a `speaker_id` index that fixes 60s+ stalls on long meetings.
- **memories pipeline** silently stopped updating — now back online.
- **macOS memory leaks** — wrapped clipboard capture, monitor enumeration, and focus-tracker callbacks in autorelease pools.
- **search results** — keyword flat mode no longer drops entries that lack text positions.
- **OAuth flows** — auto-refresh of expired tokens in the generic proxy, query params now forwarded through the connection proxy, broader Google Sheets scope, and a fix for tokens being dropped when reconnecting an instance.
- **notifications** — clicking "Open" on a native macOS notification now reliably brings the screenpipe window forward.
- **onboarding** — MCP install uses the bundled bun, so it works without a system bun on `PATH`. WhatsApp connection now resolves bun the same way.
- **calendar permission** — recovers when the macOS Privacy pane reports denied-but-empty.
- **chat polish** — drag-select restored in user messages, "+ new chat" reuses an empty chat instead of spawning duplicates, "Try again" appears when a model returns an empty response, and free models are always allowed regardless of quota.
- **Windows** — restored ARM64 release builds, switched consumer release to SSL.com EV signing, and propagated system root CAs to bundled bun/node via `NODE_EXTRA_CA_CERTS`.
