## week of may 3, 2026

### new features

- **owned agent browser** — a built-in browser embeds as a right-side sidebar so pi can navigate, snapshot, and act on web pages alongside your chat. configure browser backends from **settings → browsers**.
- **meeting notes top-level view** — meetings get their own sidebar entry with a two-pane notepad, a "coming up" calendar section, auto-enrichment of the active meeting, and a timeline scrubber that replaces the old per-row drawer. see [meeting transcription](/meeting-transcription).
- **replay-the-moment + receipts** — jump from any meeting note back to the exact second on the timeline, with citation receipts on summary bundles.
- **clipboard-capture privacy toggle** — disable clipboard capture from the UI or via a CLI flag if you'd rather keep copied text out of the index. see the [CLI reference](/cli-reference).
- **retention controls** — one-click delete of the last 15 / 30 / 60 minutes of recordings, plus a new `--retention-mode` CLI flag with a media-only mode that reclaims disk space while keeping search results alive.
- **one-off scheduled pipes** — schedule a pipe to run once at a specific time with `schedule: at <iso>`. see [pipes](/pipes).
- **queue follow-up prompts** — type your next question while pi is still streaming; queued messages run automatically when the current turn finishes.
- **tray pause submenu** — pause recording for 5/15/30/60 minutes from the tray with auto-resume and a live tooltip showing remaining time.
- **Connections in the main sidebar** — connections moved out of settings into a dedicated top-level nav entry. see [connections](/connections).
- **new connections** — Zoom OAuth, Supabase, Bee wearable, Hermes Agent, and a Warp MCP card. configure in **settings → connections**.
- **Jira OAuth 2.0 (3LO)** — Jira now uses standard OAuth instead of the legacy flow, with the maintainer banner removed.
- **MCP server LAN access** — `--listen-on-lan` and `--api-key` flags for the MCP HTTP server so other devices on your network can reach it. see the [MCP server docs](/mcp-server).
- **`screenpipe install <manifest-url>`** — install pipe bundles in one CLI call. see the [CLI reference](/cli-reference).
- **streaming onboarding recap** — "here's what i picked up" prose now streams live with thumbnails as screenpipe finishes its first scan.
- **per-line accessibility capture** — multi-line accessibility text nodes now get per-line bounding boxes for tighter highlights, including a Chromium-browser fallback.
- **single recording quality knob** — one slider replaces the old split controls so text on ultrawide displays stays readable.
- **help cards** — the help menu now surfaces quick links to documentation and video tutorials.

### updates

- **chat works without login** — start chatting immediately; the yellow "log in" banner is gone for free / pay-as-you-go users.
- **api keys** — settings now supports cancel, apply, and manual edit alongside regenerate, with the encryption toggle fixed.
- **OpenAI model picker** — fetches the live model catalog instead of hardcoding gpt-4 only; ChatGPT preset OAuth UX cleaned up.
- **meeting notes layout** — single-column granola layout, card-style "coming up", denser past-meetings list, dates on older meetings, and focused mode auto-collapses the sidebar.
- **timeline search** — ⌘G to jump between hits, dot-strip overview, and corrected forward/back chevron direction.
- **chat polish** — queued messages are de-emphasised, the first thought block collapses by default, sidebar dot pulses while the current chat streams, and rename events broadcast across windows.
- **notifications** — file links open in the in-app viewer instead of bouncing through the OS, and links no longer double-encode.
- **tinfoil E2EE proxy routes** — additional ai-gateway routes now flow through the Tinfoil enclave.

### bug fixes

- **chat reliability** — user messages persist on send, stuck "writing…" indicators self-heal on session return, streaming state survives turn boundaries, and history loss / ENOENT on concurrent saves are fixed. Windows users no longer lose pipe-run sessions to filename sanitization.
- **owned browser** — embedded webview now spoofs Safari so x.com loads, screen-coord math is correct, parent-window resolution is more forgiving, and tray-only mode is supported.
- **browser extension** — MV3 keepalive every 30s, eligible-tab picking, and unified routing under `/connections/browser` to stop status flapping.
- **remote sync** — `VACUUM INTO` snapshot prevents corrupt `db.sqlite` during SSH/SFTP sync.
- **retention** — "delete last N minutes" now actually unlinks mp4/wav files and drops cached frames.
- **timeline + windows** — empty-state arrow buttons go the right way, and Escape closes the overlay timeline when opened from search on Windows.
- **audio** — zero-fill watchdog only trips after a stream is healthy, preventing false device-hijack triggers; bluetooth hijack-recovery test added.
- **OCR / a11y** — Apple per-word records preserved on the level-0 fast path; macOS `NSPasteboard` access serialized to fix a memory issue.
- **pipes** — disabling a pipe works even when its connections are missing, tab navigation is client-side, and stale installs are guarded with a UI cancel button.
- **theme + UI** — dark/light mode inconsistency with Tauri integration resolved, title text hidden on login + Google Calendar OAuth webviews, console flashes silenced on Windows.
- **MCP tools** — relative date parsing in `list-meetings`, correct field names in `merge-speakers`.
- **performance** — pipe-store list query no longer ships ~830 MB per call; vision-stall false alarms quieted by ticking write-timestamps on dedup-skips.

## week of april 26, 2026

### new features

- **new integrations** — connect [Microsoft 365 and Teams](/connections), Google Docs, Google Sheets, QuickBooks Online, Bitrix24, Loops, Resend, Supabase, and the Pocket AI voice recorder. configure in **settings → connections**.
- **PII privacy filter** — opt-in filter (powered by a Tinfoil enclave) that redacts personal info from `/search` results and chat messages before they leave your machine. toggle from the chat composer. [learn more](/privacy-filter).
- **parallel chats with background streaming** — start multiple chats and switch between them; responses keep streaming in the background. a new chat sidebar shows pinned chats, recents, and pipes scheduled to run.
- **focus-aware capture** — when enabled, screenpipe only records the focused monitor instead of all of them, halving capture cost on multi-display setups. toggle from settings.
- **per-machine pipe favorites** — star pipes you use most. starred pipes sort to the top of the pipe list and get their own filter chip.
- **LAN-access toggle for the API** — bind the local API to `0.0.0.0` so other devices on your network can reach it. API auth is force-enabled when LAN access is on. see the [API docs](/for-developers).
- **`screenpipe sync remote`** — back up your screenpipe data over SSH/SFTP to a server you control. see the [CLI reference](/cli-reference).
- **`screenpipe db {check, recover, cleanup, unlock}`** — new CLI commands to repair database corruption and reclaim disk space. see the [CLI reference](/cli-reference).
- **`screenpipe logout`** — sign out of your screenpipe cloud account from the CLI.
- **connected apps as @mentions in chat** — type `@` in the chat filter popover to scope a question to a specific connected integration.
- **AI quota warnings** — heads-up notice when you're close to your daily limit on weighted models, so you don't get cut off mid-task.
- **browser extension v0.2** — new popup with connection status, an options page, and token-based auth.

### updates

- **CoreAudio Process Tap is now the default for system audio** on macOS 14.4 and later — better quality and no virtual driver required.
- **API keys are now readable and regeneratable** in the UI. user-set custom keys have been removed in favor of a single managed key.
- **Cursor-style inline edit** — click any of your past chat messages to edit and re-run it.
- **redesigned sidebar** — collapse button next to the macOS traffic lights, search opens a focused overlay window with a real keyboard shortcut, and starred pipes outrank running pipes in sort order.
- **timeline calendar** — empty days are now disabled in the day picker and skipped when navigating with arrow keys.
- **chat models hot-swap** — switching a preset's model no longer restarts the chat subprocess.

### bug fixes

- **mic stays connected on sleep/wake** — fixed false-positive disconnects.
- **Microsoft 365 / Teams OAuth** now uses the correct Azure client ID; personal Microsoft accounts are rejected up-front (Teams scope isn't supported there).
- **database reliability** — multibyte string truncation no longer panics, and connection starvation under heavy writes has been resolved.
- **diarization timeouts** — added a `speaker_id` index that fixes 60s+ stalls on long meetings.
- **memories pipeline** silently stopped updating — now back online.
- **macOS memory leaks** — wrapped clipboard capture, monitor enumeration, and focus-tracker callbacks in autorelease pools.
- **search results** — keyword flat mode no longer drops entries that lack text positions.
- **OAuth flows** — auto-refresh of expired tokens in the generic proxy, query params now forwarded through the connection proxy, broader Google Sheets scope, and a fix for tokens being dropped when reconnecting an instance.
- **notifications** — clicking "Open" on a native macOS notification now reliably brings the screenpipe window forward.
- **onboarding** — MCP install uses the bundled bun, so it works without a system bun on `PATH`. WhatsApp connection now resolves bun the same way.
- **calendar permission** — recovers when the macOS Privacy pane reports denied-but-empty.
- **chat polish** — drag-select restored in user messages, "+ new chat" reuses an empty chat instead of spawning duplicates, "Try again" appears when a model returns an empty response, and free models are always allowed regardless of quota.
- **Windows** — restored ARM64 release builds, switched consumer release to SSL.com EV signing, and propagated system root CAs to bundled bun/node via `NODE_EXTRA_CA_CERTS`.
