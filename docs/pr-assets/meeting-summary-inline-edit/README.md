# Meeting workspace previews

Fictional meeting data rendered with production React components in the browser-mock frontend. These are not packaged desktop screenshots.

- `before.png`, `after.png`, `editing.png`: isolated Summary component; summary baseline `5713950a1`.
- `header-before.png`, `header-after.png`: full NoteView fixture at the same viewport, data and light theme; header baseline `7e0c5d90f`.
- `header-*-detail.png`: same-pixel header crops of the corresponding full screenshots.
- `header-tooltip.png`: keyboard focus on the Google Meet source icon.
- `header-menu.png`: calendar connections in the existing overflow menu.
- `header-dark.png`: dark theme with the eligible contextual calendar prompt preserved.

The temporary preview routes and fixtures were removed after validation.

Bundled Google Meet logo source: https://fonts.gstatic.com/s/i/productlogos/meet_2020q4/v6/web-48dp/logo_meet_2020q4_color_2x_web_48dp.png (retrieved October 7, 2026). The meeting UI loads the local asset and makes no external logo request.
