# resume work

Resolve which task the user wants to resume. Search recent Screenpipe activity with screenpipe-api for that project or artifact, then inspect a small window around the last relevant work.

Recover the objective, last verified result, unfinished step, and any error or pending operation. Check the current file, job, or service before continuing when available; an old screen or chat preview does not establish that a process finished.

Return a brief checkpoint and continue work already authorized by the current request. Avoid repeating external writes that may have completed during the interruption; inspect their receipt or state first. When the next action depends on missing information, state that gap instead of inventing prior intent.
