# commitment review

Resolve the person or project and review period. Use screenpipe-api to retrieve relevant meetings and conversations. Extract explicit commitments with the original speaker, action, date wording, and source; keep tentative ideas separate.

Search for later updates or completion evidence for each commitment. Verify current connected records when available, and report unchecked channels. A drafted message is not sent, a planned meeting is not held, and an opened ticket is not resolved.

Present confirmed open, completed, superseded, and uncertain items. Resolve relative deadlines using the source's date and timezone, retaining ambiguity. Prioritize by stated deadlines and dependencies. Do not contact people, create reminders, or edit task systems unless covered by the user's request or standing instructions.
